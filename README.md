# Ground 🧬

Ground — учебное веб-приложение по биологии: короткая теория, применение знаний, объяснение ответов и личный прогресс. Интерфейс на русском языке, адаптирован для телефона и компьютера.

## Запуск

Приложение использует HTML, CSS и JavaScript без сборки, npm-зависимостей и сервера API. Из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Открой `http://127.0.0.1:8000` в браузере. Для размещения достаточно любого статического хостинга, включая GitHub Pages. Все пути относительные: приложение работает и в подкаталоге сайта.

## Что работает

- Выбор школьного курса 7–11 классов, подготовки к ЕНТ или олимпиадного направления; смена курса без потери прогресса.
- 19 учебных уроков с 139 вопросами, включая первый урок 8 класса с 12 вопросами, кейсы и анализ таблицы экспериментальных данных. Это начальная подборка тем, а не полный школьный курс или официальный банк ЕНТ.
- Смешанные уроки: короткие фрагменты теории чередуются с заданиями. Объяснение появляется после проверки ответа. Варианты ответов перемешиваются при начале попытки.
- Последовательная дорожка. Следующий урок открывается после результата не менее 70%. Повторное прохождение доступно; награды начисляются один раз за занятие.
- Итоговое испытание курсов 8–11 классов, ЕНТ и олимпиад с таймером на пять минут. В 7 классе итоговый тест находится внутри урока из файла и не имеет таймера. Неотвеченные вопросы учитываются в результате. Выход из испытания не останавливает таймер.
- XP, уровни, гены, серия дней, цель на день, достижения и история последних 50 попыток. Гены пока являются показателем наград, магазин не реализован.
- Выход и продолжение незавершённого урока, в том числе после перезагрузки. Одновременно сохраняется одна незавершённая попытка.
- Тренировка случайных вопросов и отдельная работа над ошибками; тренировка поддерживает серию, но не начисляет XP и не открывает уроки.
- Поиск в библиотеке, конспекты тем курса, авторский конспект «Химический контекст жизни» из четырёх разделов и проверка из шести вопросов. Проверка доступна после открытия всех разделов; её награда начисляется один раз.
- Просмотр двух существующих страниц Campbell Biology (47 и 48). Полная книга и отсутствующие страницы не включены. Авторский конспект Ground — самостоятельный материал, не перевод учебника.
- Переключатель **Профиль → Настройки → Вид интерфейса**: «Авто» подстраивается под экран, «Ноутбук» показывает меню слева, «Телефон» — узкий интерфейс с меню снизу. Выбор сохраняется после перезагрузки и входит в резервную копию.
- Настройка имени, экспорт и импорт JSON-копии прогресса с проверкой формата, подтверждение замены данных и сброса.
- Семантические элементы интерфейса, видимый фокус, диалоги, поддержка уменьшенных анимаций и клавиатурный выбор ответа клавишами 1–9. Escape в уроке сохраняет место и возвращает на главную.

## Хранение данных

Прогресс хранится в `localStorage` под ключом `ground.v2` и относится к текущему браузеру и адресу сайта. Очистка данных сайта удаляет прогресс. Для переноса используй **Профиль → Настройки → Экспорт / Импорт**. Экспорт содержит имя, ответы, историю и учебную статистику; передавай его осознанно.

Курс 7 класса заменён уроками из пользовательских файлов: старые отметки прохождения прежних тем 7 класса не переносятся в новые уроки. XP, гены, предпочтение интерфейса и прогресс остальных курсов сохраняются.

При первом открытии новой версии переносится доступная статистика прежней версии: XP, гены, выбранный класс и отметки обычных уроков `ground_<grade>_lesson_<id>_complete`. Старые ключи не удаляются. Сброс новой версии не выполняет повторный перенос, потому что сохраняет новый пустой профиль.

Облачной регистрации, синхронизации между устройствами, платежей и магазина нет. Для них потребуются отдельные серверные компоненты. Эта версия не запрашивает секреты и не отправляет учебный прогресс на сервер. Данные локальной игры не являются защищёнными экзаменационными результатами.

## Структура

| Файл                     | Назначение                                                    |
| ------------------------ | ------------------------------------------------------------- |
| `index.html`             | Точка входа и подключение ресурсов                            |
| `css/style.css`          | Адаптивный интерфейс и визуальная система                     |
| `js/database.js`         | Курсы, теория, вопросы и библиотечный конспект                |
| `js/player.js`           | Правила шагов урока, оценка, награды, открытие этапов и серия |
| `js/app.js`              | Экраны, навигация, таймер, профиль и хранение данных          |
| `images/`                | Существующий маскот и изображения страниц                     |
| `tests/player.test.cjs`  | Проверки учебных правил и структуры данных                    |
| `tests/browser_smoke.py` | Сквозные браузерные проверки                                  |

При добавлении урока укажи уникальный последовательный `id`, заголовок, описание, теорию и вопросы с `answers`, индексом `correct` и `explanation`. В курсах с итоговым испытанием оно является последним уроком. Для 7 класса действует отдельная структура из 13 кружков, описанная ниже. При изменении структуры уже опубликованных курсов сохраняй ключи пройденных уроков или добавляй миграцию.

## Проверки

Для тестов правил нужен Node.js 18 или новее:

```sh
node --test tests/player.test.cjs
```

Для браузерных тестов нужны Python 3, Python-пакет Playwright и Chromium. В подготовленной облачной среде они уже установлены. Для самостоятельной установки используй `python3 -m pip install playwright`, затем `python3 -m playwright install chromium`; Тесты используют системный Chromium, если он найден, иначе браузер Playwright. При необходимости укажи путь переменной `CHROMIUM_PATH`.

```sh
python3 tests/browser_smoke.py
```

Браузерный набор сам запускает временный HTTP-сервер на свободном порту. Он проверяет урок с ошибкой и объяснением, выход и продолжение, отсутствие повторных наград, открытие этапов, тренировку ошибок, библиотеку и экзамен, таймер, направления обучения, настройки, экспорт/импорт, перенос прежних данных и отсутствие горизонтального переполнения при ширине 360–1440 пикселей.

## 7 класс: 13 уроков из файлов

В дорожке ровно 13 кружков. Один присланный PDF занимает один кружок; подразделы документа находятся внутри него. Отдельного четырнадцатого кружка для экзамена нет.

Сейчас заполнены два кружка. Кружок 1 — **«Экосистемы»**. Внутри сохранены введение, пять подразделов, 25 вопросов для устной/письменной самопроверки, итоговое повторение и 40 интерактивных вопросов из PDF. Проверка оценивает только итоговые 40 вопросов, зачёт — **28/40**. Правильные ответы соответствуют ключу файла; пояснения к ответам добавлены для приложения. Исходный PDF с иллюстрациями доступен по ссылке в уроке и библиотечном конспекте.

Кружок 2 — **«Классификация живых организмов»**: введение, четыре подраздела, 20 вопросов для самопроверки, повторение и 40 интерактивных вопросов из второго PDF. Зачёт — **28/40**; исходный файл доступен в уроке и библиотеке. Второй кружок открывается после зачёта первого; прежний прогресс «Экосистем» сохраняется.

Кружки 3–13 пока имеют статус «Файл ещё не добавлен» и остаются недоступными даже после зачёта второго урока. Следующие файлы нужно добавлять в существующие позиции с сохранением ID; темы остальных файлов не выдумываются. Правило закреплено в `AGENTS.md`.
