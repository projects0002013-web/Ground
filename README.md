# Ground 🧬

Ground — учебное веб-приложение по биологии: короткая теория, применение знаний, объяснение ответов и личный прогресс. Интерфейс на русском языке, адаптирован для телефона и компьютера.

## Запуск

Интерфейс использует HTML, CSS и JavaScript; официальный Firebase SDK уже собран и сохранён в репозитории. Гостевой режим работает локально, Google-вход и облачный прогресс используют Firebase Auth и Firestore на бесплатном тарифе Spark. Настройка проекта и установка безопасных правил: [docs/FIREBASE_SETUP.md](docs/FIREBASE_SETUP.md). Для запуска статического интерфейса npm не нужен. Из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Открой `http://127.0.0.1:8000` в браузере. Для размещения достаточно любого статического хостинга, включая GitHub Pages. Все пути относительные: приложение работает и в подкаталоге сайта.

## Что работает

- Выбор школьного курса 7–11 классов, подготовки к ЕНТ или олимпиадного направления; смена курса без потери прогресса.
- Курсы из присланных файлов: 7 класс — 13 кружков, 8 — 14, 9 — 16, 10 — 13; 11 класс — 15 модулей подготовки к ЕНТ и итоговый пробник. Всего 77 обычных уроков с 1571 интерактивным вопросом и три итоговых испытания с 57 вопросами. ЕНТ и олимпиады вне курса 11 класса остаются начальной подборкой, а не официальным банком заданий.
- В курсах 7–11 классов сначала изучается конспект, затем выполняется проверка. В отдельных тренировочных курсах теория чередуется с заданиями. Объяснение появляется после проверки ответа. Варианты ответов перемешиваются при начале попытки.
- Последовательная дорожка. Следующий урок открывается после результата не менее 70%. Повторное прохождение доступно; награды начисляются один раз за занятие.
- Итоговый пробник курса 11 класса: 40 вопросов за 60 минут. Итоговые испытания отдельных направлений ЕНТ и олимпиад имеют таймер на пять минут. В 7–10 классах проверка находится внутри урока и не имеет таймера. Неотвеченные вопросы учитываются в результате. Выход из испытания не останавливает таймер.
- XP, уровни, гены, серия дней, цель на день, достижения и история последних 50 попыток. Гены пока являются показателем наград, магазин не реализован.
- Выход и продолжение незавершённого урока, в том числе после перезагрузки. Одновременно сохраняется одна незавершённая попытка.
- Тренировка случайных вопросов и отдельная работа над ошибками; тренировка поддерживает серию, но не начисляет XP и не открывает уроки.
- Поиск в библиотеке, конспекты тем курса, авторский конспект «Химический контекст жизни» из четырёх разделов и проверка из шести вопросов. Проверка доступна после открытия всех разделов; её награда начисляется один раз.
- Просмотр двух существующих страниц Campbell Biology (47 и 48). Полная книга и отсутствующие страницы не включены. Авторский конспект Ground — самостоятельный материал, не перевод учебника.
- Переключатель **Профиль → Настройки → Вид интерфейса**: «Авто» подстраивается под экран, «Ноутбук» показывает меню слева, «Телефон» — узкий интерфейс с меню снизу. Выбор сохраняется после перезагрузки и входит в резервную копию.
- Настройка имени, экспорт и импорт JSON-копии прогресса с проверкой формата, подтверждение замены данных и сброса.
- Семантические элементы интерфейса, видимый фокус, диалоги, поддержка уменьшенных анимаций и клавиатурный выбор ответа клавишами 1–9. Escape в уроке сохраняет место и возвращает на главную.

## Хранение данных

Гостевой прогресс хранится в `localStorage` под ключом `ground.v2` и относится к текущему браузеру и адресу сайта. Очистка данных сайта удаляет прогресс. Для переноса используй **Профиль → Настройки → Экспорт / Импорт**. Экспорт содержит имя, ответы, историю и учебную статистику; передавай его осознанно.

Курсы 7–11 классов используют версию прогресса 2. При замене прежних тем 8–11 классов их старые отметки и незавершённые попытки не переносятся в новые материалы. XP, гены, дни занятий, предпочтение интерфейса и актуальный прогресс 7 класса, ЕНТ и олимпиад сохраняются. При входе облачный профиль проходит такую же миграцию без изменения балансов; для неё нужны актуальные Firestore Rules.

При первом открытии новой версии переносится доступная статистика прежней версии: XP, гены, выбранный класс и совместимые отметки обычных уроков `ground_<grade>_lesson_<id>_complete`. Отметки заменённых курсов с несовместимой версией не импортируются. Старые ключи не удаляются. Сброс новой версии не выполняет повторный перенос, потому что сохраняет новый пустой профиль.

После входа через Google профиль и прогресс синхронизируются через Firestore. Приложение проверяет ответы, а транзакции Firestore сохраняют награды без повторного начисления. Правила защищают чужие профили и ограничивают награды; правильность ответов доверенным сервером не подтверждается. Для подключения нужно опубликовать правила по [инструкции Firebase](docs/FIREBASE_SETUP.md). Гостевой профиль остаётся отдельным; при первом входе в браузере предлагается перенос попыток с подтверждением. Прочитанные разделы книги объединяются, исходные даты занятий сохраняются. Достижения сохраняются в облаке и восстанавливаются на другом устройстве. Платежей и магазина нет. Учебные результаты не являются защищённым экзаменом.

При добавлении урока укажи уникальный последовательный `id`, заголовок, описание, теорию и вопросы с `answers`, индексом `correct` и `explanation`. В курсах с итоговым испытанием оно является последним уроком. Для 7 класса действует отдельная структура из 13 кружков, описанная ниже. При изменении структуры уже опубликованных курсов сохраняй ключи пройденных уроков или добавляй миграцию.

## Проверки

Для тестов правил нужен Node.js 18 или новее:

```sh
node --test tests/player.test.cjs
```

Для браузерных тестов нужны Python 3, Python-пакет Playwright и Chromium. В подготовленной облачной среде они уже установлены. Для самостоятельной установки используй `python3 -m pip install playwright`, затем `python3 -m playwright install chromium`; Тесты используют системный Chromium, если он найден, иначе браузер Playwright. При необходимости укажи путь переменной `CHROMIUM_PATH`.

```sh
python3 tests/browser_smoke.py
```

Браузерный набор сам запускает временный HTTP-сервер на свободном порту. Он проверяет урок с ошибкой и объяснением, выход и продолжение, отсутствие повторных наград, открытие этапов, тренировку ошибок, библиотеку и экзамен, таймер, направления обучения, настройки, экспорт/импорт, перенос прежних данных и отсутствие горизонтального переполнения при ширине 360–1440 пикселей.

## 7 класс: 13 уроков из файлов

В дорожке ровно 13 кружков. Один присланный PDF занимает один кружок; подразделы документа находятся внутри него. Отдельного четырнадцатого кружка для экзамена нет.

Заполнены все 13 кружков. Кружок 1 — **«Экосистемы»**. Внутри сохранены введение, пять подразделов, 25 вопросов для устной/письменной самопроверки, итоговое повторение и 40 интерактивных вопросов из PDF. Проверка оценивает только итоговые 40 вопросов, зачёт — **28/40**. Правильные ответы соответствуют ключу файла; пояснения к ответам добавлены для приложения. Исходный PDF с иллюстрациями доступен по ссылке в уроке и библиотечном конспекте.

Кружок 2 — **«Классификация живых организмов»**: введение, четыре подраздела, 20 вопросов для самопроверки, повторение и 40 интерактивных вопросов из второго PDF. Зачёт — **28/40**; исходный файл доступен в уроке и библиотеке. Второй кружок открывается после зачёта первого; прежний прогресс «Экосистем» сохраняется.

Кружки 3–13 заполнены следующими файлами:

В каждом уроке сохранены теория, самостоятельные вопросы и итоговый тест из 40 заданий с зачётом **28/40**. В сумме это **520 итоговых заданий** и **300 вопросов самопроверки** для 7 класса. Вопросы и ключи перенесены из файлов, пояснения к ответам добавлены для приложения. Исходные PDF с иллюстрациями доступны в уроках и библиотеке и хранятся в `materials/grade7/`.

Уроки открываются последовательно после зачёта предыдущего. Прогресс первых двух кружков, XP, гены и выбор интерфейса сохраняются. После всех 13 уроков доступно повторение без повторного начисления наград. Порядок и правило одного файла на кружок закреплены в `AGENTS.md`.

## Курсы 8–11 классов из файлов

| Курс                        |               Кружки | Интерактивные вопросы | Оригинальные письменные задания |
| --------------------------- | -------------------: | --------------------: | ------------------------------: |
| 8 класс                     |                   14 |     560 (40 в каждом) |              520 из уроков 2–14 |
| 9 класс                     |                   16 |   196 (12–14 в уроке) |                             640 |
| 10 класс                    |                   13 |   188 (12–28 в уроке) |                             520 |
| 11 класс / подготовка к ЕНТ | 15 модулей + пробник |               90 + 40 |                               — |

Уроки открываются последовательно после результата не менее 70%. Конспекты имеют русские объяснения, вопросы для самостоятельной проверки, объяснения тестовых ответов и ссылки на оригинальные PDF с иллюстрациями. Все 14 файлов 8 класса и все PDF из архивов 9–10 классов сохранены без изменения байтов в `materials/grade8`, `materials/grade9` и `materials/grade10`. Интенсив 11 класса сохранён в `materials/grade11`.

В PDF первого урока 8 класса есть 40 вопросов с вариантами и ключом: они перенесены в приложение. В уроках 2–14 только открытая проверка без ключа, поэтому интерактивные тесты составлены отдельно. В исходных файлах 9–10 классов также нет ключей для автоматической оценки: 40 открытых вопросов каждого файла доступны в раскрываемом блоке, а дополнительная интерактивная проверка Ground оценивается отдельно. Для 9–10 классов добавлены русские объяснения и повторение связанных понятий; это учебная адаптация, не дословный перевод полного учебника.

В 11 классе сохранены все 90 вопросов модулей и 40 вопросов пробника с исходными ответами и пояснениями. Это авторский интенсив из присланного файла, не официальный банк НЦТ. План подготовки на шесть недель находится в первом модуле.

Проверки импорта и переноса: `npm test`, `python3 tests/browser_imported.py`, `python3 tests/browser_cloud.py`, `python3 tests/browser_offline.py`. Тесты Firestore Rules в официальном эмуляторе: `npm run test:firebase` (нужны Java и доступ для загрузки эмулятора).

При блокировке окна Google на GitHub Pages разреши popup и повтори вход: redirect между разными доменами автоматически не запускается. Постоянная сессия используется, если браузер её поддерживает; при ограничениях отображается предупреждение. После обновления подключения заново опубликуй актуальный `firestore.rules` по [инструкции](docs/FIREBASE_SETUP.md). Статические пути `/Ground/` и экспорты официального SDK проверяются командой `python3 tests/browser_pages.py`; тесты SDK-адаптера не заменяют проверку реального Google-аккаунта.
